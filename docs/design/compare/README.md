- `desktop-blaatt-cover.jpg` – referansen (`../reference/high-end-studio.png`) ved siden av Vault i 1536×1024 med «Out Of Control» (blått cover).
- `desktop-roedt-cover.jpg` – samme visning med blått og rødt: hele uttrykket bytter farge, gull står bare i logoen.

**Om rødt:** ingen låt i katalogen har rødt cover ennå (bare blå/cyan og gull/varme). Det røde eksempelet bruker derfor en midlertidig manuell palett (#FF3B4E / #8A0F1E) på «Shake The Ground» via Studio → farge (del 8). Den ble tilbakestilt til coverets palett rett etterpå. Paletten var identisk før og etter. Med et faktisk rødt cover blir resultatet det samme, fordi paletten hentes fra coveret.

Stripen nederst i referansen (Font pairing / Key traits / Design vibe) er en presentasjon og er bevisst ikke bygget.
